# Frontend Wireframes

이 문서는 Email AI Aggregator 프로젝트의 프론트엔드 구성에 필요한 wireframe들을 제시합니다.

## 📱 전체 페이지 구조

```
┌─────────────────────────────────────────────────────────┐
│  Header: Logo | Search | Notifications | User Menu      │
├─────────────────────────────────────────────────────────┤
│                                                           │
│  Sidebar Navigation                                      │
│  ├─ 📧 Inbox                                            │
│  ├─ ⭐ Important                                        │
│  ├─ 📁 Folders                                          │
│  ├─ 🤖 AI Processing                                    │
│  └─ ⚙️ Settings                                         │
│                                                           │
│  Main Content Area                                       │
│  (각 페이지별 내용)                                      │
│                                                           │
└─────────────────────────────────────────────────────────┘
```

## 1. 로그인 페이지 (Login)

**경로**: `/login`

**기능**: Google SSO 로그인

```
┌─────────────────────────────────────────────────────────┐
│                                                           │
│                    📧 Email AI                           │
│                  Aggregator                              │
│                                                           │
│              여러 이메일을 한 곳에 모으고                │
│              AI가 자동으로 정리해드립니다                │
│                                                           │
│         ┌───────────────────────────────────┐            │
│         │  🔵 Google로 로그인                │            │
│         └───────────────────────────────────┘            │
│                                                           │
│         ┌───────────────────────────────────┐            │
│         │  🟢 Naver로 로그인 (준비중)        │            │
│         └───────────────────────────────────┘            │
│                                                           │
│         [이용약관] [개인정보처리방침]                      │
│                                                           │
└─────────────────────────────────────────────────────────┘
```

**주요 요소**:
- Google OAuth 로그인 버튼
- Naver 로그인 버튼 (비활성화 또는 "준비중" 표시)
- 브랜딩 및 간단한 설명

## 2. 대시보드 / 이메일 목록 (Inbox)

**경로**: `/` 또는 `/inbox`

**기능**: 수집된 이메일 목록 표시, 필터링, 검색

```
┌─────────────────────────────────────────────────────────┐

├─────────────────────────────────────────────────────────┤

├─────────────────────────────────────────────────────────┤
│                                                           │
│  ┌─────────────────────────────────────────────────┐   │
│  │ ⭐ [중요] 📎 [첨부]                              │   │
│  │ From: sender@example.com                         │   │
│  │ Subject: 중요한 회의 안내                        │   │
│  │ 📝 AI 요약: 내일 오후 2시 회의실 예약...         │   │
│  │ 2시간 전 | Gmail                                 │   │
│  └─────────────────────────────────────────────────┘   │
│                                                           │
│  ┌─────────────────────────────────────────────────┐   │
│  │ [읽지 않음]                                      │   │
│  │ From: newsletter@example.com                     │   │
│  │ Subject: 주간 뉴스레터                           │   │
│  │ 📝 AI 요약: 이번 주 주요 뉴스...                 │   │
│  │ 5시간 전 | Gmail                                 │   │
│  └─────────────────────────────────────────────────┘   │
│                                                           │
│  ┌─────────────────────────────────────────────────┐   │
│  │ ⏳ [AI 처리 중]                                   │   │

│  │ AI가 이메일을 분석 중입니다...                    │   │
│  │ 10분 전 | Gmail                                  │   │
│  └─────────────────────────────────────────────────┘   │
│                                                           │
│  ┌─────────────────────────────────────────────────┐   │
│  │ [PENDING]                                        │   │
│  │ From: spam@example.com                          │   │
│  │ Subject: 광고 메일                               │   │
│  │ 아직 AI 처리가 되지 않았습니다                    │   │

│  └─────────────────────────────────────────────────┘   │
│                                                           │

│                                                           │
└─────────────────────────────────────────────────────────┘
```

**주요 요소**:
- 검색 바
- 필터 버튼 (전체, 읽지 않음, 중요, AI 처리됨, 미처리)
- 이메일 카드 (발신자, 제목, AI 요약, 시간, 계정)
- 상태 표시 (읽지 않음, 중요, AI 처리 중, PENDING)
- 페이지네이션
- 계정 연결 버튼

## 🎨 디자인 가이드라인

### 색상
- **Primary**: 이메일 브랜드 색상 (예: Gmail 빨강, Naver 초록)
- **Success**: 초록색 (처리 완료, 성공)
- **Warning**: 노란색 (처리 중, 대기)
- **Error**: 빨간색 (오류, 실패)
- **Info**: 파란색 (정보, 알림)

### 타이포그래피
- **제목**: 18-24px, Bold
- **본문**: 14-16px, Regular
- **요약**: 12-14px, Regular
- **메타데이터**: 12px, Light

### 간격
- **카드 간격**: 8-12px
- **섹션 간격**: 24-32px
- **패딩**: 16-24px

### 반응형
- **모바일**: 1열 레이아웃, 사이드바 숨김
- **태블릿**: 2열 레이아웃
- **데스크톱**: 3열 레이아웃, 전체 사이드바

## 🔄 사용자 플로우

### 1. 로그인 플로우
```
로그인 페이지 → Google OAuth → 콜백 → 대시보드
```

### 2. 계정 연결 플로우
```
설정 > 계정 연결 → Gmail OAuth → 콜백 → 계정 목록 업데이트
```

### 3. 이메일 읽기 플로우
```
이메일 목록 → 이메일 클릭 → 상세 보기 → AI 분석 결과 확인
```

### 4. AI 처리 플로우
```
이메일 수집 (PENDING) → AI 처리 시작 (PROCESSING) → 
요약/분류/검색 → 처리 완료 (PROCESSED) → 사용자에게 알림
```
